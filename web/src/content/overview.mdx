This tutorial deploys the NVIDIA AI-Q Blueprint on Kubernetes from a Brev launchable.

The launchable setup has one job: prepare a working Kubernetes environment. The AI-Q deployment itself is part of the hands-on tutorial, so you can see each resource and command involved.

## What you will do

- Inspect the single-node k3s cluster created by Ansible.
- Review the AI-Q architecture at a high level.
- Deploy the blueprint with Kubernetes and Helm commands.
- Validate the running services from the embedded terminal.

<Callout type="note" title="Setup boundary">
Ansible creates the cluster and installs cluster tooling. It does not install AI-Q.
</Callout>
