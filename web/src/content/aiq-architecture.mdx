AI-Q is deployed as Kubernetes workloads from the official blueprint Helm chart.

At this stage, keep the mental model simple:

- Kubernetes provides the runtime substrate.
- Helm templates and installs the blueprint resources.
- Secrets provide credentials needed by the services.
- Port-forwarding or ingress exposes the UI/API surfaces for testing.

## Deployment shape

The tutorial will use the source chart from:

```text
deploy/helm/deployment-k8s
```

The exact values and credentials will be added in the deployment chapter as the tutorial content becomes more complete.
