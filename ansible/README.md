# Ansible Structure

This directory follows the same broad pattern as the reference launchable:

- `site.yml` coordinates host preparation, k3s, and Kubernetes tooling.
- `inventory/hosts.ini` is generated by `scripts/setup.sh` for a single Brev VM.
- `inventory/group_vars/all.yml` holds committed defaults.
- `inventory/group_vars/secrets.yml` is generated from `.env` and is gitignored.
- Roles are numbered by order of execution.

Run a full setup from the repository root:

```bash
./scripts/setup.sh
```

Run a subset:

```bash
ANSIBLE_TAGS=k3s ./scripts/setup.sh
```

AI-Q deployment is intentionally not modeled as an Ansible role. The hands-on tutorial will have the user run the Kubernetes and Helm commands directly against the prepared cluster.
